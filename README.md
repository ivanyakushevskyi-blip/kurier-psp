# Кур'єр: Хмельницький (PSP)

Хобі-гра для PSP: кур'єр на Golf V розвозить замовлення справжнім центром Хмельницького.

- Дизайн і рішення: [docs/design.md](docs/design.md)
- Інструкції для Claude Code: [CLAUDE.md](CLAUDE.md)
- Збірка: `./scripts/setup.sh` один раз, потім `./scripts/build.sh --host` → `dist/KurierKhm_PSP.zip`
